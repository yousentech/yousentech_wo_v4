# شاشة أجزاء السيارات

## الهدف

تعريف مناطق العمل مثل الزجاج الأمامي والصدام والمقاعد وربط كل جزء بصنف خدمي.

## المستخدمون ومتى تستخدم

مدير المركز بعد التهيئة عند إضافة جزء جديد أو تعديل ترتيب ظهوره. موظفو التشغيل
يقرأون الأجزاء فقط.

## الحقول والأزرار

الكود، الاسم، الشركة، الصنف الخدمي، ترتيب الأولوية، نسبة العمولة، نوع الجزء،
الخيارات الإضافية والحالة. زر الأرشفة يحفظ العلاقات السابقة.

## خطوات الاستخدام

أنشئ الصنف الخدمي أولًا، ثم افتح «أجزاء السيارات»، أدخل كودًا ثابتًا واسمًا،
واختر الصنف والخيارات واحفظ.

## التحقق والأخطاء والصلاحيات

الكود والاسم فريدان داخل الشركة، والعمولة بين 0 و100، والصنف إلزامي ومن الشركة
المسموحة. المستخدم يقرأ، والمدير ينشئ ويعدل ويؤرشف دون حذف.

## الشاشات المرتبطة والأثر

يرتبط بالفيلم والتسعير والعمولة، وسيظهر في أمر التركيب. لا ينشئ فاتورة أو صرف
مخزون أو ضمانًا بنفسه.

## مثال عملي

الجزء `TINT-FRONT` يمثل الزجاج الأمامي ويرتبط بصنف خدمة، ثم يضاف إلى فيلم
العزل بسعر وعمولة حسب الحجم.

## عقد التكامل مع Flutter

القراءة تستخدم `public_uuid`, `code`, `name`, `part_type`, `active`. لا يعتمد
Flutter على ID داخلي. تعديل الفني غير مسموح. أخطاء متوقعة:
`CAR_PART_DUPLICATE`, `PRODUCT_NOT_ALLOWED`, `COMPANY_NOT_ALLOWED`.
