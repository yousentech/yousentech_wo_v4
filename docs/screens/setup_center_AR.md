# شاشة مركز الإعدادات والجاهزية

## الهدف والمستخدمون

لوحة ما بعد التشغيل لمدير المركز ومسؤول التهيئة. تفصل الإدارة اليومية المتقدمة
عن معالج البداية السريع.

## المزايا والحقول

- مؤشرات عدد الخدمات والأفلام والأحجام والأسعار الصفرية.
- فتح الخدمات والأفلام والتسعير والعمولات مباشرة.
- عرض سياسة الدفع والخصم والمواعيد والمخزون؛ تعديلها لمسؤول التهيئة فقط.
- عرض نسخة التهيئة وتاريخ الإكمال.

## متى تستخدم

بعد تفعيل النظام لأي تعديل يومي أو فحص نقص في الأسعار، بدل إعادة مسار البداية
كل مرة.

## الأزرار وخطوات الاستخدام

1. أزرار المؤشرات تفتح الشاشة المرتبطة مع تقييد الشركة.
2. مسؤول التهيئة يعدّل سياسة التشغيل، ومدير المركز يفتح البيانات المتقدمة.
3. «إعادة فتح التهيئة الأولى» يعيد الحالة إلى قيد التهيئة ولا يحذف البيانات.

## التحقق والأخطاء والصلاحيات

نفس قواعد ملف الشركة وتطبق صلاحيات Odoo وrecord rules. مدير المركز يقرأ
اللوحة ويفتح الشاشات المرتبطة، ومسؤول التهيئة وحده يعدّل ملف الشركة أو يعيد
فتح المعالج. الشركة غير المسموحة تُرفض برسالة واضحة. إدراج سجل التدقيق هو
الاستثناء الخادمي المحدود ولا يوسع صلاحية العملية.

## الشاشات المرتبطة والأثر

التغييرات التشغيلية ستكون مرجعًا لأمر التركيب والفوترة والمخزون والعمولات
عند تنفيذ تلك المراحل. الشاشة لا تنشئ فاتورة أو صرفًا أو ضمانًا بنفسها.

## مثال عملي

عند ظهور «سعر يحتاج مراجعة»، يفتح المدير قائمة الأسعار المصفاة للشركة ويكمل
السعر قبل بدء استقبال الأوامر.

## عقد التكامل مع Flutter

- القراءة: ملخص الجاهزية والإحصاءات والأكواد التقنية.
- العمليات: لا يحتاج تطبيق الفني لتعديل هذه الشاشة.
- الصلاحيات: قراءة للمدير؛ تعديل ملف التشغيل لمسؤول التهيئة.
- الأخطاء: `ACCESS_DENIED`, `COMPANY_NOT_ALLOWED`, `SETUP_PROFILE_NOT_FOUND`.
