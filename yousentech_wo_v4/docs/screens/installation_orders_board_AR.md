# لوحة أوامر التركيب

## الهدف والمستخدمون

نقطة الدخول اليومية للاستقبال والفني والمشرف والمحاسب ومدير المركز. تعرض
الأوامر ككانبان حسب المرحلة، أو قائمة قابلة للفرز، مع بحث موحد دون فتح كل أمر.

## متى تستخدم

- الاستقبال: إنشاء أمر والعثور عليه بالعميل أو اللوحة.
- الفني: متابعة الأوامر المسندة وحالة التنفيذ.
- المشرف: معرفة الضغط والأوامر المنتظرة للجودة أو التسليم.
- المحاسب: قراءة الإجماليات والروابط المالية دون تعديل التشغيل.

## الحقول والإجراءات

تظهر رقم الأمر، العميل، اللوحة، الموعد، المرحلة، تقدم التنفيذ، الفنيين والإجمالي.
زر «جديد» ينشئ مسودة. المرشحات الجاهزة: أوامري، مواعيد اليوم، الأوامر المفتوحة،
الجاهزة، المسلمة والملغاة. التجميع متاح بالحالة أو المستشار أو الفرع أو اليوم.

## خطوات الاستخدام

1. افتح «العناية بالسيارات ← العمليات ← أوامر التركيب».
2. استخدم الكانبان لمتابعة المراحل، أو بدّل للقائمة للمقارنة السريعة.
3. ابحث برقم الأمر أو العميل أو اللوحة أو رقم الهيكل.
4. افتح البطاقة، أو أنشئ أمرًا جديدًا إن كنت من الاستقبال أو الإشراف.

## التحقق والأخطاء الشائعة

- إذا لم يكتمل إعداد الفرع تظهر رسالة تطلب إكمال التهيئة الأولى.
- لا تعرض قواعد الشركات إلا أوامر `allowed_company_ids`.
- الفني يستطيع قراءة اللوحة، لكن تعديلات التنفيذ محمية داخل الأمر وبالإسناد.

## الصلاحيات والشاشات المرتبطة

القراءة لكل أدوار نظام العناية. الإنشاء للاستقبال والمشرف/المدير. لا يوجد حذف؛
الإلغاء ثم الأرشفة هما المسار الآمن. تفتح البطاقة شاشة «أمر التركيب»، ومنها
الخدمات والاستلام والتنفيذ والجودة والسجل.

## الأثر على الفاتورة والمخزون والضمان

اللوحة تعرض إجمالي الخدمات المحسوب. لا تنشئ فاتورة أو صرفًا أو ضمانًا؛ تظهر
الروابط فقط عندما تنشئها المراحل اللاحقة.

## عقد التكامل مع Flutter

- القراءة المخططة: `GET /api/v1/installation-orders` باستخدام cursor وUUID.
- الإنشاء المخطط: `POST /api/v1/installation-orders` مع `Idempotency-Key`.
- الحالات أكواد ثابتة: `draft`, `scheduled`, `intake`, `in_progress`,
  `quality`, `ready`, `delivered`, `cancelled`.
- الصلاحيات والشركة تطبق بهوية الموظف ولا تقبل IDs داخلية.
- أخطاء متوقعة: `SETUP_NOT_READY`, `FORBIDDEN`, `VALIDATION_ERROR`,
  `IDEMPOTENCY_CONFLICT`.
- Flutter غير منفذ، والمسارات موثقة فقط حتى مراجعة المصادقة.
